# 数据看板与保存报价单

依据用户提供的1442×1026看板截图及需求（部分）.md第1节。沿用确认的main #f8fbff，不使用示例数字或虚假金银铂钯数据。用户确认先展示铱损耗、增加保存报价单并统计已保存数量。

/index为默认看板，无侧栏；顶栏82px，品牌左对齐，右侧后台管理按钮和当前用户。后台管理进入第一个获授权业务页；业务侧栏首页改名数据看板，返回/index。删除单据模板配置入口。

布局：上方三个100px高统计卡片分散排列；中排左60%损耗趋势、右40%工序TOP5，高353px；下排29%工厂损耗、29%预警饼图、42%预警中心，最低447px。按1442宽度系数缩放，高度不足可滚动，图表随尺寸调整并释放实例。

统计按上海日期。工单统计所有未删除工单，分别列进行中/已完成；待处理为当前全部有效待处理预警，今日新增按触发日期，今日已处理按处理日期。损耗以已结算有效报工的结算日期汇总，排除作废报工；30日逐日补零，只展示真实铱曲线。本月TOP5按工序ID汇总净损耗，名称取当前工序名称，按损耗降序、ID升序。工厂柱图本月总损耗g；预警饼图按本月触发且未归档/未作废记录分厂计数。预警中心最新6条，列时间、工厂、工序、预警值（阈值）、状态，更多进入有权限的预警记录页。普通人员全部统计限本厂，管理员全厂，接口只允许认证用户。

自动报价新增保存报价单：具有metal:quotation:add权限才能保存，不自动授权已有演示角色。管理员选择保存所属工厂，普通人员固定本厂。保存时服务端按当前锁定报价规则重新计算所有商品，存规则和尺寸快照；仅已保存报价计入本月数量与覆盖类别。原计算接口不写数据，重复计算不会增加报价单数。UUID幂等，相同请求只保存一次，改动商品或工厂后重新生成请求ID。历史未保存计算不补录。

V11新增metal_saved_quotation和保存权限。POST /metal/quotation/save字段requestId、factoryId、items(category,quantity,dimensions)，返回id、quoteNo、totalPrice、items、ruleVersion、createTime。编号QT+上海日期+6位流水；报价只读不修改历史价格。GET /metal/quotation/factories、/quotation/orders/{id}均检查权限范围。保存报价引用阻止工厂删除。

GET /metal/dashboard返回workOrders、warnings、quotations、trend、ranking、factories、distribution、warningCenter、asOf和metal。重量与金额字符串、ID字符串；空数据展示0与真实空状态，无随机统计。默认登录看板可读，按钮按业务权限控制，不增加写入能力。

验收：新保存报价只增加一次，计算不增加；坏尺寸拒绝且不留单；修改报价规则不改历史快照；跨厂请求拒绝；报工冲销从趋势排行移除；预警处理更新处理数但不改损耗。检查默认首页、刷新、后台返回、1442/1920布局、空状态、图表及旧报价功能。
