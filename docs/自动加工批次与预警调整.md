# 自动加工批次与预警调整

2026-10-13已按用户确认实施：加工批次不再是独立操作页面，预警规则不再配置超差。V14追加唯一batch_no，隐藏旧页面，保留历史关系表及必要技术接口。

## 操作流程

生产出库选择工厂、生产工单、产品明细和工序。加工批次号只读：首次显示保存时生成，已有未结算记录时显示已绑定的号码。确认出库时后端在同一事务自动生成批次并过账；失败整体回滚，不留空批次。相同工单/产品明细/工序的多次领料、半成品/成品产出及原料还库自动复用唯一未结算批次。外部入库不选生产工单，不生成生产批次。

格式为工单号-上海时间yyyyMMddHHmmssSSS-工单产品编号快照。唯一索引+冲突检查确保不同批次编号不重复；展示编号不是主键，关系继续使用内部稳定ID。号码生成后不随产品改名或编号修改改变。既有历史批次补充带H及原主键尾缀的号码以避免碰撞，不重算历史报工/预警。若同一工序存在多个历史未结算批次，自动绑定会拒绝模糊归属，提示先结算或冲销多余历史批次。

自动批次容量采用当前可加工的剩余数量：首工序为工单数量减已完成量；后工序为前道已完成量减本工序已完成量。同工序一次只复用一个未结算批次，结算时填写实际完成数量，释放未完成部分。前道未完成时不允许生成后道批次。

选择生产产出的入库或原料还库后，自动绑定现有未结算号码；没有批次时提示先生产领料。末张单可勾选本批次结算；若此前已保存全部产出，可从仓储工单的物料清单详情填写实际完成数量并结算，不需要再添加假单据。冲销关联生产单据时入口明确提示整体冲销本批次全部单据，保留后续引用检查和库存反向变动检查。

原始引用检查、工厂隔离、数量约束、UUID幂等、版本、来源快照、损耗分摊及事务回滚继续生效。自动绑定在工厂锁内读取当前状态；重复请求首先检查已保存单据，不重复开批次或扣库存。

## 预警

批次平均损耗=（有效领料净重-有效原料还库净重-有效半成品/成品产出净重）÷实际完成数量。实际平均损耗严格大于创建工单时保存的工序单件理论损耗时异常，相等或小于正常。使用交叉相乘比较，不以显示舍入判定。

新报工tolerance固定0，threshold=工单理论损耗快照，ruleId/ruleVersion为空。旧规则不参与新结算，规则维护接口拒绝新增修改；旧报工和预警仍保留当时阈值，不追溯改写。预警记录、处理和归档功能保留，处理不改变真实异常判定。
