# 报价产品类型目录联动

## 行为与接口

报价产品类型改为当前工厂在类型管理中维护的产品类型。没有配置时保持空目录，不回退到固定八种选项；管理员先选择工厂，普通账号使用所属工厂。切换工厂清空金属、产品类型和尺寸，保留其他填写内容。

复用 `GET /metal/quotation/context?factoryId=...`，其中 `productTypes` 仍为标准名称数组，查询 `metal_product_type` 并按名称、ID 排序。报价权限即可读取，不需要类型维护权限。

`POST /metal/quotation/calculate` 和 `POST /metal/quotation/save` 的新计算校验本厂目录。保存沿用原工厂锁和事务，与类型改名、删除互斥；保存包装商品错误时保留校验错误码。类型已有报价引用时，原引用保护继续阻止改名、删除。

前端展开下拉、页面重新获得焦点及原定时刷新时更新目录，忽略旧工厂请求。目录加载失败可重试并阻止提交；已选类型失效时保留输入，提示重新选择。提交结果未知时仍使用原请求标识核实已保存结果。

历史报价继续按原快照查看、下载，原请求重放可返回原记录，不要求历史类型重新进入目录。公式、密度、单价、计价方法与类型维护权限未改变。无数据库迁移，版本仍为 V64，不植入默认类型。
