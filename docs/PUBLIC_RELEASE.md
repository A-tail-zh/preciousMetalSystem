# 当前版本交付与验证

当前版本包含基础资料、工单计划与审批、仓储单据、库存流水与调整、自动生产批次、工序损耗报工、理论损耗预警、报价保存下载、数据看板和日志管理。

日志与安全修复覆盖：完整脱敏归档及校验、认证头和Cookie脱敏、报价审计工厂归属、密码与手机号修改后的全部会话注销、工厂隔离、日志队列批量投递及失败重试、分阶段清理、仓储导入校验和历史引用保护。日志清理默认关闭。

前后端构建通过。本轮后端测试通过，另完成3项浏览器回归、日志队列一万条隔离测试及真实接口验证。实时接口测试需要自行配置隔离环境，不能直接针对生产数据运行。

本地测试环境已备份并缩减为5组关联业务，保留5个账号及对应角色。报工1条正常、4条异常；库存15条、仓储单据25条，关联流水保持完整，余额校验无差异。清理时操作、登录、系统日志各保留最近5条，新操作仍正常记录。数据库备份、账号清单、日志原文及运行时数据没有提交到公开仓库。

浏览器标签页使用系统蓝色Logo，404页使用纯文字。部署凭据由环境变量提供：TOKEN_SECRET、MYSQL_PASSWORD、ADMIN_PASSWORD_HASH等。Druid控制台默认关闭，如需启用，须另行提供DRUID_USERNAME和DRUID_PASSWORD。正式建库使用Flyway V1～V19，历史迁移保持原样；不提供含默认密码哈希的上游示例建库SQL。
