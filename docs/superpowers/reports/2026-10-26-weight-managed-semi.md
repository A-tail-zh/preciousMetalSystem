# 粉料半成品重量管理实施报告

日期：2026-10-26。范围：本地开发环境；不提交、推送 GitHub。保留工作区原有修改。

## 实施结果

| 能力 | 状态与实际行为 |
|---|---|
| 计量模式 | 产品工艺步骤可配置 PIECE/WEIGHT，保存到工单、批次、库存来源快照；最终成品步骤仍按件管理 |
| 半成品入库 | WEIGHT 必填正净重，参考件数选填；空值不转换成1，不参与生产额度 |
| 领料 | 校验真实库存、释放剩余净重及路线；按件外部接入容量和重量库存分别展示，不再把32件显示为粉料可领数量 |
| 还库 | 恢复原库存重量及原释放额度，减少净投入；保持原来源，不自动新增释放 |
| 释放 | 支持仅有重量的真实剩余库存；正常完成自动释放，部分关闭保持单独确认；库存调整不能绕过释放保护 |
| 库存调整 | 参考件数余额可以人工补记，不能改变生产覆盖能力；重新打开清空上次输入 |
| 结算 | 重量批次不要求虚假的实际完成件数；损耗按净投入和产出重量计算，按件平均损耗不适用 |
| 工序进度 | 重量步骤单独结束生产；真实领入的半成品及合法来源路线决定覆盖；最终成品继续受计划件数限制 |
| 冲销 | 按真实依赖恢复库存、释放与接入；多条原始流水冲销后恢复完整参考件数，存在其他有效流转时保持未完整记录 |
| 导入、导出 | 旧模板兼容；新增参考件数，预览与保存均检查计量模式和批次重量余额 |
| 权限、审计 | 保留现有权限与隔离；新增重量步骤操作审计按真实工单归属，防止把产品明细/工序ID当作工单ID |
