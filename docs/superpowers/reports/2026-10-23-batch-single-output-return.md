# 加工批次一次入库与还料确认交付报告

## 已完成

实施计划的7个功能阶段已完成，代码保留在当前工作区，未提交或推送 GitHub。

1. 新建批次采用 `SINGLE_OUTPUT_RETURN`：半成品/成品合计只允许一次有效产出入库；重复请求重放不重复记账。
2. 新增统一还料确认：原料、未加工半成品、加工余料可一次提交多种物料、多来源出库单、多仓库；按原单据类型分组记账。
3. 无余料由操作人确认实物核对，不生成零重虚假还料单；无余料说明选填，重量差额仍计损耗。
4. 产出及还料确认齐全后，同事务结算本批、生成报工和预警、刷新工单状态；实际完成件数来自有效产出明细合计。
5. 部分完成可继续处理剩余计划；足额不再超额建批。下一工序入口预选上下文，仍需实际领料，不自动扣库存。
6. 旧保存、导入和独立结算不能绕过新规则；保留权限、工厂隔离、版本、库存/来源校验和既有释放规则。错误且未确认的产出可单独冲销重录；已结算确认组走完整批次冲销。
7. V32新增策略及确认关系，历史批次维持LEGACY；没有自动改写、合并或结算历史业务。

附加界面调整：添加物料窗口加大，4个物料类型完整展开；新还料来源下拉限制视口宽度、长文字换行，半成品展示来源工序、工单、批次；加工余料无可选工序时增加条件说明。
