# 入库产品候选按生产工单明细限定

采用用户批准计划，不提交 GitHub。

## 实现

- 绑定生产工单的半成品、成品入库，候选只取当前 itemId 对应的 productId 与工单快照。文案为编号 / 名称 / 规格型号；未填规格显示“未填写规格型号”。
- 仓储专用上下文 Snapshot 增加 specification；不扩展权限，不调用生产工单完整详情接口，不增加数据库字段。
- 未选明细或依赖加载期间禁用产品选择；切换明细或工序时关闭物料弹窗、清空旧清单、选中行及结算值。工厂、工单、类型切换沿用既有失效机制。
- 单条确认、导入追加、保存前均检查当前产品和类别。导入捕获工厂、工单、明细、工序及类型上下文，迟到响应不能追加到其他上下文。
- 无工单入库、原材料和期初库存保持既有候选规则；后端保存、导入、工厂隔离和重量计算规则保留。

## 验证

先运行新增回归：前端3项失败、1项兼容用例通过；后端快照白名单测试失败。修复后再运行针对性与完整回归。

覆盖两种产出类型、多产品明细、同产品重复明细、切换草稿清理、旧响应、合法及错误产品导入、外部入库兼容；真实 Chrome 使用隔离账号录入，实际 XLSX 错误产品导入和保存应拒绝。
