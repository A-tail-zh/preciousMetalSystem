## 有效问题及修复

1. 报价规则保存、体积参数保存、删除确认，以及新增金属，缺少 Cookie 与 Store/草稿身份的一致性检查。同厂账号切换后仍可能把 A 的草稿记作 B 的操作。复用工序类型控件已有的 session/identity 做法：打开草稿绑定身份和工厂；校验/确认后、请求拦截器发送前、发布响应前都重新校验。自动报价同类入口一并校验。
2. BusinessFilters 普通账号切换后保留旧厂隐藏条件，无法恢复查询。身份变化时清理并重建工厂及关联条件，初始化和候选请求绑定身份、工厂和代次，迟到旧响应不再发布。
3. 客户创建 HTTP 200 但没有有效 ID 也属于结果未知，不能再次创建。保留输入、锁定重复提交，核对后才能关闭；沿用现有网络未知结果交互。
4. 清理 WorkOrderForm 文件末尾多余空行，不改业务行为。
