# 仓储物料确认即预占 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Do not commit or push.

**Goal:** 出库明细确认即原子占用实物及料权，关闭释放、断连30分钟失效，复验消费，精确提示不足。
**Architecture:** 独立新仓储预占表，工厂锁串行化余额变化。编辑会话整体替换预占，60秒续租；待复验绑定单据后永久有效，账务扣减保护所有其他有效占用。
**Tech Stack:** Java/Spring/JdbcTemplate/MySQL/Flyway，Vue/TypeScript/Element Plus。
**Spec:** docs/storage-reservation-design-20261110.md，用户2026-11-11明确要求实施与本地启动。

## Constraints and rulings
- 保留当前工作区全部未提交依赖；当前分支开发，不另建丢失依赖的工作树；不提交/推送。不恢复旧模块、不写正式测试单据。
- 复核下一Flyway版本，新增结构，不改变历史账务；新预占不使用旧metal_stock_reservation。
- 预占减少可用量，不减少实物/料权余额；异常30分钟无心跳后查询即视为失效，不能依赖定时任务准点执行。
- 保留未知提交结果核实，重复请求幂等，编辑原子替换失败保留原占用。
- 历史待复验单不代退回或代换来源；无有效预占的旧出库复验须明确提示发起人重新提交。发布前只读核查并披露。

## Tasks
- [ ] 后端：新增预占迁移、会话/明细占用服务与接口。工厂及持有账号校验、原子整单替换/续租/释放/请求核实，OUT提交绑定及复验消费，退回撤销释放。
- [ ] 账务：在统一实物/料权扣减点保护有效占用，覆盖调整、还债及冲销；候选显示可用与占用，默认客户优先工厂其次，按重量和件数分别检查。
- [ ] 前端：WarehouseOrderForm/LineEditor共享会话，确认成功才更新行、CSV全批原子确认；所有丢弃/关闭/切换路径释放，隐藏页仍续租，断连/结果未知保留输入并核实。
- [ ] 验证：先写失败回归，再实现；隔离库并发竞争、替换失败回滚、过期与绑定、跨厂/跨人、超额复验、其他扣减保护、历史待复验兼容；UI确认/取消/关闭/断连/CSV/错误输入保留。
- [ ] 最终复审与本地切换：前后端检查、构建、真实接口/browser验收；备份并恢复验证数据库，备份运行产物，停本地服务部署；局域网只读验收。不将安全回退到不识别预占的旧版本作为默认操作。

## Review focus
1. 关闭请求与提交并发：关闭只能释放临时占用，不能释放已绑定单据。
2. 同单重复库存/所有权行：合计校验，不能逐行通过后超额占用。
3. 重放返回已过期占用：不能仅凭旧成功结果提交，应再次核实有效状态。
4. 未提交退出与异常关闭：退出清理尽力通知，无法送达最多30分钟占用。
5. 正式库旧待复验单：不暗改业务事实，不宣称已获得有效预占。
