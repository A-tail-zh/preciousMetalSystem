# 类型管理真实对接与本地部署记录

日期：2026-11-09。已实施、验收并部署；未提交或推送 Git。

## 使用入口与范围

访问 http://127.0.0.1:5173/metal/type-management （另一前端端口 5220，后端 8080）。已有页面请刷新。

基础信息管理 → 类型管理，包含金属、产品、物料三个页签。管理员明确选择真实工厂；普通账号固定所属工厂。当前正式库工厂为零，因此页面显示先建立工厂的引导，添加按钮禁用。本次未导入示例、未自动生成默认类型。

产品类型只能选择：平底坩埚、环、杆、梯形、弧底、靶、方形坩埚、方形盖。选项来源为 `ProductTypes.ALL`；服务端再次校验，数据库检查约束拒绝其他名称。每厂独立添加，已添加项禁选，编辑当前项可选，全部添加后禁用新增。

金属和物料类型支持 1～100 字名称。同厂同分类唯一；其他工厂可同名。引用保护覆盖软删除业务资料，金属还检查原有报价、批次、库存及报价快照；产品检查同厂产品、库存类型快照和报价快照。引用记录不能改名或删除。

产品、物料、报价录入页面使用工厂类型目录的联动未实施，现有计算公式保持不变。旧金属内嵌新增、删除入口已接入统一服务和新权限。旧工单、仓储、酸洗等入口继续停用。

## 接口

分类 `kind` 仅允许 `metal`、`product`、`material`，服务端使用固定表映射。

| 方法与地址 | 请求与返回 |
| --- | --- |
| GET `/metal/type-management/{kind}/list` | `factoryId,name,pageNum=1,pageSize=16`；返回 `rows,total,code,msg`，最多 64 条，更新时间和 ID 倒序 |
| GET `/metal/type-management/{kind}/{id}` | `factoryId`；返回最新记录及版本 |
| POST `/metal/type-management/{kind}` | JSON `factoryId,name`；返回新增记录 |
| PUT `/metal/type-management/{kind}/{id}` | JSON `factoryId,name,version`；返回新版本 |
| POST `/metal/type-management/{kind}/batch-delete` | JSON `factoryId,items:[{id,version}]`，1～100 条，不接受重复 ID；统一检查后整批删除 |
| GET `/metal/type-management/product/formula-options` | 返回上述 8 个标准名称 |

记录字段：字符串 `id,factoryId`，`factoryName,name,version,createTime,updatedAt`。管理员必须传工厂；普通账号省略时取所属工厂，伪造其他工厂被拒绝。错误沿用现有 AjaxResult 的业务 `code`：400 参数、403 权限、404 不存在/归属不符、409 重名/版本/引用冲突；客户端不能仅根据 HTTP 200 判断成功。

每类独立权限 `metal:metal-type:{list,add,edit,remove}`、`metal:product-type:{list,add,edit,remove}`、`metal:material-type:{list,add,edit,remove}`。菜单和角色编辑已接入；任一分类查看权限显示入口，默认首个可查看页签。角色保存自动补齐类型页面菜单。旧金属查询兼容保留，旧写入使用新权限。

写入采用事务、工厂锁、记录锁、版本校验和数据库唯一约束；审计记录分类、工厂、对象、变更前后内容。前端不自动重试写入；网络未知结果先核实，版本冲突保留输入并要求重新加载。切换工厂/页签清空筛选、勾选并回首页，过期响应不落入新上下文。
