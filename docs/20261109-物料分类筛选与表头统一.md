# 物料分类筛选与表头统一

物料管理增加物料分类下拉筛选：旧料、粉料、块料。支持单独查询及与工厂、类型名称、编码等组合，重置及切换工厂清空分类。管理员未选工厂时可按分类查询全部有权查看的物料；普通账号仍受所属工厂限制。

物料管理表头及类型名称筛选统一为“物料类型名称”，分类表头和筛选为“物料分类”。物料列表接口 `GET /metal/material/list` 增加可选参数 `materialCategory`，后台验证三种分类，按物料所属工厂及类型名称匹配目录分类后分页。未设置分类或未关联目录的历史物料仍出现在无分类筛选的列表中，不会按名称推断分类。

无需数据库结构修改，仍为 V63，无业务数据改写。未扩展生产、仓储功能，无 Git 提交或推送。
