# 产品类型与产品管理对接

产品管理新增、编辑和列表筛选改为读取本厂已配置的产品类型，不再从固定八种类型及旧别名列表直接提供选择。八种公式和尺寸计算逻辑保持不变。

## 接口及兼容

- `GET /metal/options/product-types?factoryId=...`：返回全部 `{id,name}`，名称、ID 排序；允许产品 list/query/add/edit 任一权限，不要求类型维护权限。管理员指定工厂，普通账号固定所属工厂。
- 新产品、更换类型及旧版转新版时，在工厂锁内查询本厂目录并锁定记录，拒绝未配置、跨厂、已删除或改名的选项。产品类型引用检查改为锁定读，避免等待工厂锁之后读取旧快照而误删、误改类型。
- 历史产品保持原类型时可继续维护；下拉中保留禁选的历史项，变更必须选本厂目录。旧版尺寸、计算版本保护沿用原逻辑。
- 编辑打开和下拉展开刷新目录，切换工厂清空类型和尺寸，忽略过期响应。加载失败保留输入、可重试且禁止保存。空目录提示先在类型管理添加，不回退固定选项。
- 产品筛选仅包含本厂维护类型；管理员未选工厂时类型筛选禁用，仍可查看全部有权查看的产品。
- 产品、物料共用目录加载流程；物料分类显示和筛选保持。纯计算预览保留原公式能力，最终保存以目录校验为准。报价页面范围不在本次联动中。

无数据库结构变更，仍为 V63；没有创建默认类型、改写历史产品或向正式库植入示例。
