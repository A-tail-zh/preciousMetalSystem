# 公共体积参数补齐与工厂初始化修复

## 原因与改动

工厂 13514 的计算规则接口报错：公共模板 `metal_volume_rule` 和本厂 `metal_factory_volume_rule` 均缺失。原工厂新增逻辑使用 INSERT SELECT，模板不存在时插入零行，仍提交成功；读取时抛出空结果异常。

- V64 只补齐缺失的公共模板和有效工厂参数，默认 π=3.14、弧底系数=1.03。已有参数不覆盖，历史迁移不修改。
- 新建工厂在同一事务内保证模板存在，再初始化工厂参数；初始化数量异常则回滚。
- 缺失参数查询改为明确的业务错误，避免通用 500，也不在查询中静默写数据。
- 八种体积公式继续共用现有 ProductGeometry：平底坩埚、环、杆、梯形、弧底、靶、方形坩埚、方形盖。保留原工厂参数配置能力，没有复制或改变公式实现。
- 不自动添加工厂产品类型目录。产品下拉仍按类型管理中已配置的类型显示。未补造金属密度或报价数据。
