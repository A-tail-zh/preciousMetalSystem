# 仓储与损耗统计使用说明

1. 管理员进入仓库字典，选择工厂建立并启用库房；在角色管理按岗位配置新仓储、批次、报工和预警权限，已有演示人员不自动获得新权限。
2. 库存管理的添加登记期初，或仓储工单管理→入库单登记原料入库。选择本厂库房、经手人和仓管员，添加物料清单后确认生效。
3. 生产工单先审核通过。在加工批次建立工单→产品明细→工序批次，填写加工数量。
4. 仓储工单→出库单→生产出库，关联批次，选择库存、填写领料净重（半成品另填件数）并确认。
5. 归还剩余原料使用还库单→原料还库，绑定同批次原领料明细。产出使用入库单→半成品/成品入库，填写实测净重和数量并关联批次。
6. 全部领回料登记后，在最后一次回料/产出单中勾选本批次结算并填写实际完成数量，或在加工批次查看中结算。产出数量必须等于完成数量。
7. 工单详情左侧自动显示当前产品的每道工序损耗，查看可看各批次物料分摊及来源单据。右侧仍只显示计划时间。
8. 预警规则配置本厂产品工序允许超差（g），未配置按0g；异常自动进入预警记录，去处理填写处理结果后留痕。处理不会改变损耗。
9. 下一工序可领前一道已结算的同产品明细半成品。全部工序累计达到工单数量且无未结算批次，工单自动已完成。
10. 已生效单据不直接改删。非生产单在物料清单详情冲销；生产单从加工批次整体冲销。已被后续业务引用时需先处理后续业务，系统检查库存与数量能否恢复。

损耗=(领料-归还原料-半成品产出-成品产出)/实际完成数量，单位g/件；汇总平均使用总损耗/总数量，物料按领用净重比例分摊。退给客户的还料出库和未关联批次的外部出入库不计生产损耗。

侧栏单据模板配置已移除；仓储表单物料模板下载和导入保留。导入只是填表，确认后才改变库存。

仓储新增表单按出库、入库、还库Tab显示对应类型及日期；入库仅原材料入库、成品入库、半成品入库。经办人可多选本厂启用人员（1～20位），名单和姓名快照保存到单据，旧单人接口继续兼容。V12追加名单字段，并保留所有经办人的历史引用保护。

生产出库弹窗按最新图片采用纵向字段与下方物料清单。生产出库经办人选填（可多选），领用人和仓管员必填；V13允许单据经办人主字段为空。其他单据沿用原校验。保留工厂、产品明细、工序、加工批次以支撑分批损耗；必填项用红色星号标记。页面整体取消1442宽度等比缩放，采用正常尺寸和自适应内容区。

最新流程以自动加工批次与预警调整.md为准：没有独立加工批次/预警规则页面。生产领料自动创建并绑定批次号，产出还料自动复用，仓储详情可结算和整批冲销。新预警只使用工单保存的理论损耗，无允许超差。
