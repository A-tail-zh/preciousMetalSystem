# 同工单生产链路与仓储刷新验证记录

本记录归档于第4轮复审发起前，记录截至冻结时的实现及实测；后续审查、提交与推送结果以交付消息和Git记录为准。本文区分当前实现、实际执行证据和待完成门槛；计划不是已完成功能的证明。开发分支为 `feature/warehouse-loss-warning`，基线 HEAD 为 `f64219e471a6395f11f086ddb6df82aa7c9e59d9`。本轮没有新增数据库迁移，也未改写已执行迁移。

## 实现与历史边界

- 常规创建直接选择最终产品及完整路线；独立原料加工保留次级入口。新工单执行策略为3，既有策略2及其计量、路线、损耗、报工快照不变。
- 前处理产出RAW、融定中间产出SEMI、产品末道FINISHED；同单同明细已结算的部分RAW可承接相邻后工序。有本单真实重量工序时，其结束投产及结算仍是完工条件，资格不能代替真实加工。外部合格来源及受控跳步按原约束处理。
- 库存及流水补来源工单/明细/工序/批次/阶段与下游工单关联。内部循环不重复算新增投入；混料、客户/厂料归属、双称差异和原重量总账分别保留。
- 工单、库存、仓储单据/交接及相关客户、工厂和基础资料页面默认可见5秒检查，焦点返回补查；隐藏暂停、失败退避。编辑只读探测变化，保留草稿和旧版本；结果未知时冻结原请求内容和UUID，显式重试。
- 历史独立酸洗移到工单历史入口；只有旧仓储读取权限且没有工单菜单的账号仍有只读可达入口，未扩展工单写权限。旧查询、续办和整批冲销保留，禁止新独立酸洗。
- 工单/仓储相关表格、表内输入及操作居中；不修改全站表单布局。原料列表只有物料编码、物料类型、规格型号、客户公司名称和净重，来源及资格在详情保留。原料无件数；成品/半成品有效及参考件数规则保留。
- 不是全站改造：报价及报价规则独立页面未接本轮5秒轮询。共用产品/计量/金属规则属于生产快照依赖，实际提交范围另有逐文件清单。
