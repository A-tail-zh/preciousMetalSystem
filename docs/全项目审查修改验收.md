# 全项目审查修改验收

日期：2026-10-14（Asia/Shanghai）。

## 实施结果

1. 个人改密事务保存并注销全部会话；数据库auth_version校验阻止旧缓存复活。登录成功日志在令牌创建成功后记录。
2. 密码统一至少8位、最多72个UTF-8字节，不裁剪密码空格。
3. 普通人员手机号同步user_name，版本冲突与重复手机号拒绝；改变手机号重新登录，管理员保持admin。
4. 日志采用100条批次事务、SKIP LOCKED、每轮最多1000条/2秒预算，坏事件独立重试；新增队列匹配索引。
5. 报工详情返回batchVersion和batchStatus，纠错不调用隐藏批次查询；无报工查看权限不显示空操作列。
6. 库存添加使用warehouse-order:add权限，旧期初入口不恢复。
7. 导入返回choiceId、编码、名称、规格和字符串ID，编辑无需重选，累计明细最多1000行。
8. 导入必须传factoryId、warehouseId、type及适用生产关联；后端检查本厂、库房、来源、分类和重量，预览不过账。
9. 清理分阶段RUNNING/FAILED续跑，全部完成才SUCCESS；截止时间固定，累计数量可查，开关保持关闭。
10. 人员删除检查工单负责人、提交与审批历史引用，批量任一失败整批拒绝。
