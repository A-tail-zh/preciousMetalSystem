## 页面与原型对应
库存原材料列：物料编码、品名、规格型号、仓库/库房、净重、更新时间、操作；成品半成品列：物料编码、批次号、品名、规格型号、仓库/库房、纯度、单位名称、数量、更新时间、操作。原料品名取物料类型。出库/入库/还库三Tab，原图纵向表单和物料清单；出库类型生产、产品、换料、半成品；入库原料、成品、半成品；还库原料、成品退还。标题误写改为实际业务词。
库房按工厂隔离，名称、排序、启用状态CRUD。生产单据补充工单→产品明细→工序→加工批次。成品半成品补充实测净重。经手人、仓管员必填，其余依类型：生产出库及半成品出库领用人必填；原料还库经手人/仓管员必填；原料/成品入库经手人/仓管员必填。审核人只记录选填，不设置审批。每单一个工厂、库房、日期，明细1～1000。
原型没有的库房导航、库存调整、分批结算、冲销、规则表单标为补充设计。预警记录只自动生成，移除添加编辑，保留归档；待处理显示去处理、已处理显示查看。已过账单据编辑删除禁用，查看物料清单提供冲销。库存期初通过过账生成流水；修改未引用快照与调整余额分离。下载/导入Excel模板只填充明细，不自动保存。

## 字段与公式
ID/DECIMAL返回字符串，version整数；重量DECIMAL(20,6)/g，纯度0～100%，数量正整数最多1000000；毛重杂质非负，净重=毛重-杂质或直接录入。快照含编码、品名、类别、规格、工厂库房人员名称。单据编号OUT/IN/RET/ADJ+上海日期+六位序列，UUID幂等，已删除不复用。
库存键工厂/库房/分类/资料ID/批次；成品半成品单位默认件，单位名称为业务单位名称选填，原料无数量。生产产出批次产品编号+工单号+加工批次后缀，外部入库日期+单号+明细号。
每个加工批次绑定workOrderId,itemId,processId,plannedQuantity，状态OPEN/SETTLED/VOID，完成数量1～预占数量；首工序不能超工单量，后一工序不能超前一道完成数减本步已完成/预占数。
损耗=有效生产领料净重-原料回料净重-半成品产出净重-成品产出净重；净领料>0，回料不能超过领料。平均损耗=损耗/实际完成数量。阈值=工单理论损耗快照+本厂产品工序允许超差，缺失或停用按0g。平均值严格大于阈值预警，相等正常，用交叉乘法判断不使用显示舍入。物料按领料净重比例分摊，编码排序最后条吸收尾差。
一批可多次领回料，最后单可勾选结算，结算锁定。报工按当前产品明细及工序汇总总损耗/总完成量，任一有效异常批次仍显示异常。查看弹窗列物料编码、物料名称、损耗重量、平均损耗，批次选择与来源单据为补充。
预警列表列工序名称、预警值、理论损耗、产品类型、规格型号、生产单号、状态、触发时间、操作；预警值为阈值。处理结果必填500字，记录人和时间；处理不改变损耗，历史规则不重算。待处理不能归档，已处理或来源作废可逻辑归档，无站外通知。

## 数据与接口
Flyway V9及后续追加；不修改V1～V8。新增warehouse/inventory/stock_ledger/warehouse_order/warehouse_order_line/process_batch/work_report/report_material/warning_rule/warning_record/warning_history表。
API /metal/warehouse、inventory、warehouse-order、process-batch、work-report、warning-rule、warning-record，分别提供范围限定的列表详情与业务操作，不提供任意表写入。创建UUID+请求哈希+操作人幂等；编辑/启停/调整/结算/冲销/处理用version。独立菜单及按钮权限，不自动授权现有演示角色。
所有库存写入按工厂串行加锁，资料/工单依赖及库存行在检查后锁定；余额/流水/单据/结算/报工/预警同事务。不同工厂可并行，禁止负库存。批量归档整体原子性，导入不越厂。生产首次领料APPROVED→IN_PROGRESS；全部工序完成且无OPEN批次→COMPLETED。
已结算纠错整体冲销批次，未结算生产单也由批次整体冲销。无下游引用且库存逆变动可执行才允许；保留单据流水报工作废历史，预警来源作废，释放数量。非生产单可独立冲销。成品退还关联原出库行，数量和净重累计不超过原单；换料不计损耗。历史引用阻止基础资料删除，停用库房不阻止历史纠错。
