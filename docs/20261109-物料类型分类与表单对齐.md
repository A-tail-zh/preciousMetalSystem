# 物料类型分类与表单对齐

## 变更

物料类型新增、编辑弹窗依次显示所属工厂、物料类型名称、物料类型。下拉选项固定为旧料、粉料、块料，必填，不支持自由输入；列表增加物料分类列。标签文字左对齐，必填星号独立定位，不占用文字起点。

类型管理 material 写入接口增加 `materialCategory` 字段，列表和详情返回该字段。后台严格验证三种值，沿用工厂锁、权限、版本及引用保护；已引用且已设置分类的记录禁止变更分类。历史未设置记录允许补选分类；不按名字猜测。

V63 为 `metal_material_type` 新增 `material_category VARCHAR(2)` 和三种值 CHECK。历史行允许 NULL，显示“未设置”，新增或编辑提交必须选择分类。没有修改原名称、主键及物料引用。分类属于类型目录元数据，本次未恢复或改写旧生产/仓储逻辑。
