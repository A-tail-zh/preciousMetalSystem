# 基础信息统一工厂隔离

本次按用户确认统一工厂、类型、产品、产线、物料、工序、客户管理：先选择工厂，再启用筛选并加载该厂资料；切换工厂清空全部其他条件、日期、分页、旧列表和勾选；普通账号固定所属工厂。

## 实现范围

- BusinessFilters 统一工厂选择、禁用、重置和切换行为。工厂选择接口不携带当前选中工厂限制选项，普通账号范围由后端限制。
- 工厂管理也按一个工厂查看和维护；管理员未选工厂仍可创建新工厂，创建权限与原后端管理员限制保留。
- 类型管理未选工厂时名称筛选和查询禁用；保持原独立权限、类型归属与版本保护。
- 产品、产线、物料、工序、客户未选工厂时不发送列表查询，不开放新增；新增默认带入所选工厂。添加工序类型也必须先选工厂。
- 基础目录服务、客户、产线通过共同查询入口解析并验证有效工厂；工厂列表按解析后的工厂查询。输入建议同步限制为选中工厂；金属筛选值校验归属。
- 保留已有详情、修改、删除权限检查和业务引用保护。产线新增也通过 FactoryScope 解析所属工厂。没有迁移、清理或重新分配历史数据；历史未分配工厂资料不混入任何工厂列表。
- 不修改报价规则和计算公式，不恢复旧工单、仓储入口，不提交或推送 Git。
