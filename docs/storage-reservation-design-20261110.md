# 出库物料确认即占用：库存与料权预扣方案

## 已确认规则
- 点击“物料明细 → 确认”时，由后端原子校验并占用实物批次及料权份额；成功才加入/更新单据明细。
- 未提交复验时，关闭单据页面释放占用；异常断开后30分钟无续租自动失效。保存草稿不延长为永久占用，重新打开必须重新校验及占用。
- 提交复验后占用持续有效，复验通过才正式扣库存、转在制、记借还债务；退回或撤销释放。
- 预扣减少可用量，不提前减少实物账，不提前转移客户料权或建立借料债。

## 页面
- 库存及来源下拉显示可用重量/件数，区分实际余额与已占用量；计件同时检查件数及重量。
- 明细“确认”显示处理中，防止重复；服务端返回占用ID、版本和有效期。失败保留输入，指出仓库、批次、料权方、可用量、申请量和不足量。
- 未手动选择来源仍按本客户优先、工厂其次，使用真正未占用的份额；其他客户须明确指定。
- 修改明细原子替换原占用，失败保留旧占用；移除明细、取消整单或切换工厂先释放，失败不假装完成。
- 取消正在编辑的物料弹窗保留此前确认的旧明细及占用。
- CSV整批确认走相同服务，任何一行失败全批不占用。
- 未提交窗口每60秒续租，页面隐藏也不主动释放；关闭明确释放，崩溃/断网30分钟后有效期失效。重连先核实/续租，已失效时重新申请，不凭旧前端显示提交。
- 提交失败保留占用和表单；请求结果未知时按原requestId核实，不重复申请或放掉可能已绑定待复验单的占用。

## 数据与接口
- 当前源码及本地库V71，实施前复核下一迁移版本；新增独立新仓储预占表，不复用旧模块metal_stock_reservation。
- 记录工厂、发起账号、编辑会话UUID、明细UUID、单据/明细ID、库存批次、料权方、重量/件数、请求摘要、版本、状态、到期时间及操作记录。
- 复用仓储单权限和FactoryScope；新增同前缀预占、核实、续租、释放接口。读取可用量不能泄露其他工厂信息；持有UUID也不能操作他人占用。
- 锁顺序保持工厂→单据/占用→排序后的库存/料权；同请求同内容返回原占用，不同内容拒绝。
- 单据提交与占用绑定及复验任务创建同事务；复验消费占用、实物/料权/债务/在制过账同事务，失败全部回滚。
- 所有会减少实物或料权的路径统一保护其他有效占用，包括出库、调整、还债、借料和冲销；不能只在库存下拉过滤。
- 可用量=真实余额－有效占用；编辑排除本明细旧占用，但计入本单其他明细；待复验占用不受临时30分钟过期规则影响。
- 复验量不超过已占用量时不会因别人先领走而余额不足；实测发出量超过占用时不抢占其他单据，提示退回发起人补足数量并重新提交。实际较少时释放差额。

## 验收与切换
- 两人抢同批同料权只能占用不超余额；同单多行、编辑失败、删除释放、重复请求、过期及重连、CSV整批回滚。
- 草稿关闭释放，待复验持续占用；退回/撤销释放、较少实收释放差额、超额实发退回；其他扣减路径不能消耗已占用部分。
- 工厂及账号隔离、零厂方份额、重量/件数独立校验，错误精确且输入保留。
- 隔离库做真实创建、过账和并发验证；前后端检查和构建通过后，备份并验证数据库/运行产物再部署。正式库不写测试业务，不提交或推送Git。
- 本次是从“待复验不占库存”改为“物料确认即占用”的新规则。未建预占前不能承诺复验绝不缺货；完成后仍保留防超额实发的复验校验。
- 发生有效占用后不得直接回退到不识别占用的旧服务，应先暂停写入并安全处理有效占用；不恢复旧库覆盖业务事实。
