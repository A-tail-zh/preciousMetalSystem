# 自动报价与历史报价统一工厂隔离（2026-11-09）

已部署到本地后端 8080、前端 5173/5220。自动报价和历史报价共用顶部所属工厂，取消历史区独立的“全部工厂”。管理员必须先选工厂，普通账号固定本厂。只有报价查看权限的管理员也可操作顶部工厂选择。

切换工厂同步清空历史报价单号、列表、总数、分页及详情，使旧列表、详情和下载响应失效。既有自动报价输入处理规则保持不变。历史详情图片和下载请求携带工厂 ID。

## 接口与兼容

以下 GET 接口按 factoryId 校验：

- /metal/quotation/orders
- /metal/quotation/orders/{id}
- /metal/quotation/orders/{id}/download
- /metal/quotation/orders/{id}/items/{index}/image

管理员未指定工厂会被拒绝。普通账号省略参数时使用账号所属工厂；指定其他工厂或伪造其他工厂报价单 ID 均拒绝。管理员指定的工厂也必须和报价单归属一致。详情、下载和图片在输出业务内容前完成校验。

本次不修改数据库结构或迁移，仍为 V65，不重新计算或改写历史报价。旧页面需要 Ctrl+F5 刷新；使用上述接口的外部调用方需传入工厂参数。
