## 独立核对口径

- V68 库存：实物余额与全部 PHYSICAL 流水；料权余额与全部 OWNERSHIP 流水；实物与料权合计。包含原流水及冲销反向流水，避免只过滤原冲销事件造成余额失真。
- V82 份额：库存与所有份额合计；份额与份额料权；库存主体料权与同主体份额料权。迁移前无表标记“不可执行”，不记为通过。
- V70/V83 在制：INPUT/OUTPUT/RETURN/RECOVERY 的未冲销事件回放与执行表计数；在制重量 = 投入 + carry-in − carry-out − 产出 − 原样退料 − 回收 − 已确认损耗。检查负在制，以及已关闭、已转移、已取消执行的非零在制。
- carry：有效 WIP transfer（排除已撤销 operation）的入出重量、件数分别与执行表核对。精确来源的剩余重量与有来源执行的在制余额核对；库存来源与对应份额主体料权核对。
- 欠料：原欠料 − 全部核销（含负向冲销核销）= 剩余欠料；原欠料事件已冲销时余额应为零。creditor=0 表示客户欠厂；debtor=0 表示厂欠客户。工厂垫料债务与借用他客料所生债务分别按种类、主体 ID 统计，不互抵。
- 原样退料：issue allocation 的 returned 计数与未冲销 return allocation 回放一致，不超过原实收。
- 冲销：按冲销单、库存、主体、账簿将原事件与反向事件汇总，应重量、件数各自归零。
- 预占：BOUND，以及尚未过期的 TEMP，会占用料权；核对是否超主体在库余额。DRAFT/PENDING_REVIEW/RETURNED 仓储单按 ID 独立列出。
- 旧体系：metal_inventory/metal_stock_ledger、metal_batch_wip_balance、旧残料/使用、旧借还相关表单独统计，绝不与 V68 仓储/欠料合并求和。

重量与件数始终分列。WEIGHT、PIECE 按计量模式分别汇总；不同工序的投入产出不能当作整单新增物料累加。数值检查使用 Decimal/数据库 DECIMAL，无浮点容差掩盖。
