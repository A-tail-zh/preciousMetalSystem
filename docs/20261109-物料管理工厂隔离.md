# 物料管理工厂隔离

依据本次用户确认：先选择工厂再启用全部筛选；切换工厂清空原条件；普通账号固定所属工厂；后端校验归属。

## 实现

- 管理员未选工厂时，物料编码、物料类型名称、物料分类、规格型号、金属类型、日期、查询和添加均禁用，不发送物料列表请求，页面提示先选工厂。
- 选择工厂后加载本厂物料；切换工厂清空全部其他筛选、日期、勾选、旧列表，回到第一页。新增弹窗默认带入列表选择的工厂。
- 物料页的工厂下拉查询不再携带当前选中工厂作为过滤条件，管理员可重新选择其他有效工厂；服务端仍限制普通账号的工厂选项。
- 普通账号自动加载所属工厂，不显示可切换的工厂筛选；重置保留所属工厂。
- MaterialService 的带条件和无参列表入口统一解析并校验有效工厂；金属筛选值也校验所属工厂。物料编码、规格型号输入建议必须限定有效工厂。
- 新增、编辑、详情、删除沿用已有 FactoryScope、FactoryCatalogService 归属校验、禁止转厂和工厂锁。无数据库结构迁移，不修改历史物料归属，不恢复旧工单或仓储功能。
