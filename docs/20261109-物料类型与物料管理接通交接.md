# 物料类型与物料管理接通交接

2026-11-09 已部署本地 8080 后端、5173/5220 前端，数据库迁移至 V62。访问 http://127.0.0.1:5173 。未提交或推送 Git。

## 实现范围

- 物料新增、编辑、列表筛选使用当前工厂维护的物料类型，不再提供固定三种选项。类型管理的物料“未接入”说明已移除。
- `GET /metal/options/material-types?factoryId=...` 返回全部 `{id,name}`，按名称、ID 排序，不受管理列表分页限制。允许物料 list/query/add/edit 任一权限；普通账号固定自身工厂，管理员必须指定工厂。类型维护权限保持独立。
- 物料保存继续传名称，在共用工厂锁内查询本厂目录，并保存目录中的标准名称。拒绝跨厂、失效、伪造及超过 100 字的名称。类型引用检查使用锁定读，防止等待工厂锁后读到旧快照而误删、误改已引用类型。
- 历史名称不改写。已有记录保持原类型时可以修改其他字段；更换必须选有效目录项。历史项禁选，不进入筛选目录。
- 弹窗打开、下拉展开刷新目录；切换工厂清空选择并忽略过期响应。加载失败可重试，保留输入且阻止提交。目录为空时提示先维护类型，无固定选项回退。
- V62 将 `metal_material.material_type` 扩为 VARCHAR(100)、utf8mb4_unicode_ci；原三名称 CHECK 改为非空白 CHECK。未改历史迁移、主键、名称或引用，未补建默认目录。
